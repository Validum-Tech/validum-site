Инструменты Validum Связанный набор

Набор, который держится вместе

Один прогон создаёт организации, людей и ИП, где каждый работодатель существует в том же наборе. Связь держится на employerOgrn: сначала вставляются организации, потом люди, потом ИП — а откат идёт обратным порядком.

организации

люди · ссылаются на ОГРН

ИП

Набор целиком

    1 организации — они ни на кого не ссылаются
    2 люди — employerOgrn уже существует
    3 ИП — тоже с работодателем
    ↩откат: validum_ip → validum_individual → validum_organization

    Спецификация и команда

    
  
    

  
    Набор собирается теми же правилами, что в продукте: ОГРН (13 знаков, остаток по модулю 11),
  ИНН ФЛ/ИП (12 знаков, два контрольных разряда), СНИЛС (mod 101), счёт по письму Банка России № 515.
  Ссылка employerOgrn указывает на ОГРН из этого же набора — в АБС такая вставка не упадёт на внешнем ключе.
  Страница автономная: значения считаются в браузере и служат иллюстрацией, реальные данные даёт
  validum generate --spec set.json.
