Что есть у ФЛ, ИП и ЮЛ

Один экран — вся поверхность профилей. Слева реквизит, дальше три колонки: кто его получает, и чем он проверяется в продукте. Ниже — форматы выдачи и валидаторы, которые можно позвать отдельно.

реквизиты и проверки

форматы выдачи

--format json один объект

Профиль целиком, вложенные группы passport, addresses, bank, cards.

REST POST /api/v1/generate/individualCLI --format json

--format json-array массив

Список профилей без обёртки — удобно для jq и загрузки в Mongo.

REST POST …/batch?format=json-arrayCLI --format json-array

--format csv машинный

69 колонок, запятая, без BOM. Для конвейеров и загрузчиков.

REST POST …/batch?format=csvCLI --format csv

--format csv-semicolon для Excel

BOM, ;, русские заголовки, длинные числа обёрнуты ="…" — Excel не съедает нули.

аlias csv-excelCLI --format csv-semicolon

--format sql засев БД

DDL + INSERT, типы по колонке: terrorist/blocked — boolean, age — целое, остальное текст.

диалекты postgres · oracle · mysqlCLI --format sql --dialect postgres

--format json-nested как в REST

Профиль объектом, группы те же, что в DTO: passport, addresses, bank, cards.

CLI --format json-nestedс 0.5.0

как позвать

# сгенерировать и проверить сразу
java -jar validum.jar generate individual --seed 42 --count 3 --format csv > out.csv
java -jar validum.jar coverage --file out.csv

# то же по REST
curl -s localhost:8080/api/v1/generate/individual -H 'Content-Type: application/json' \
  -d '{"seed":42,"age":34}'
curl -s localhost:8080/api/v1/validate/inn -H 'Content-Type: application/json' \
  -d '{"inn":"779370501280"}'

# юрлицо: ОГРН, КПП, ОКПО, ОКВЭД и счёт 40702
java -jar validum.jar generate organization --seed 42 --count 2 --format json-nested

Колонки: 69 у физлица, 72 у ИП (профиль ФЛ + ogrnip, okved, okvedName) и 21 у юрлица. Пресет --fields short оставляет 15 человеческих колонок — остальное остаётся в JSON. Значения на этой странице — примеры из продукта; генератор и валидаторы работают офлайн.

Чего в матрице нет намеренно: четыре вида ДУЛ (миграционная карта, свидетельства о рождении и смерти, паспорт моряка) не реализованы, пока нет акта с разрядностью; встроенного демо-справочника БИК тоже нет — без файла ED807.xml банковские поля дают ошибку, а не «примерные» цифры.
