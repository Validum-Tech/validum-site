как собрать


# set.json — спецификация набора
{
  "type": "set",
  "seed": 42,
  "asOf": "2026-11-20",
  "output": "out/set.csv",
  "members": [
    { "name": "orgs",    "kind": "organization", "count": 1 },
    { "name": "people",  "kind": "individual",   "count": 5, "employer": "orgs" },
    { "name": "ip",      "kind": "ip",           "count": 1, "employer": "orgs" }
  ]
}

# одна команда — пять файлов рядом с out/set.csv
java -jar validum.jar generate --spec set.json --output out/set.csv
# → out/set-organizations.csv  out/set-individuals.csv  out/set-ip.csv
# → out/set-relations.csv      out/set-teardown.sql

# проверить, что связи и суммы сходятся
java -jar validum.jar coverage --file out/set-individuals.csv

# то же через REST — одна организация, трое сотрудников
curl -s localhost:8080/api/v1/generate/organization -H 'Content-Type: application/json' \
  -d '{"seed":42}' | head -20




  Seed каждого участника выводится из общего: seed + номер × 10007, поэтому набор воспроизводится целиком —
  тот же seed и asOf дают те же файлы. Таблица связей пишется только если хотя бы у одного
  участника задан employer; скрипт отката — если в спецификации не указано "teardown": false.
